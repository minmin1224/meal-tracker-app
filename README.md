# 食事管理アプリ

写真から食事内容とカロリーをAIで自動判定し、朝食・昼食・夕食・間食を記録できる個人用Webアプリです。体重・血圧(朝夕)も記録し、体重の推移はグラフで確認できます。

- インストール不要、ブラウザだけで動作します
- データはすべて端末内(localStorage)に保存され、外部サーバーには送信されません
- 写真からのカロリー判定機能を使う場合のみ、ご自身のAnthropic APIキーを登録し、写真がAnthropicのAPIへ送信されます
- スマートフォンのホーム画面に追加してPWAとして利用できます

## 公開URL

`index.html` がランディングページ、`app/index.html` がアプリ本体です。GitHub Pagesではリポジトリのルート(このファイル)がそのまま公開されます。

## ローカルでの動作確認

```
python -m http.server 8000
```

その後 `http://localhost:8000/` を開いてください(PWA機能はhttp(s)配信時のみ動作します)。
