朝食・昼食・夕食・間食

食事の種類ごとに記録を分けて管理。1日の合計カロリーと、設定した目標との差を自動計算します。

体重の記録とグラフ表示

日々の体重を記録し、推移を折れ線グラフで可視化。前回比の増減もひと目でわかります。

🩺

血圧(朝・夕)の記録

朝と夕、2回に分けて収縮期・拡張期・脈拍を記録。こちらもグラフで推移を確認できます。

💾

データは端末内に保存

記録はすべてお使いのブラウザ内にのみ保存され、外部のサーバーには送信されません。JSON形式でバックアップ・復元も可能です。

📲

使い方

むずかしい設定は不要です

  1. 「アプリを起動する」を押すインストール不要、ブラウザですぐ使えます。
  2. (任意)設定タブでAPIキーを登録写真からのカロリー自動判定を使う場合は、ご自身のAnthropic APIキーを登録してください。未登録でも手動入力で記録できます。
  3. 食事・体重・血圧を記録写真を撮る、または数値を入力するだけ。過去の記録も一覧で確認できます。
  4. 体重・血圧の推移をグラフで確認体重タブ・血圧タブでこれまでの変化をチェックできます。
  5. ホーム画面に追加(任意)毎日使うなら、ホーム画面に追加しておくとアプリのようにすぐ開けて便利です。

写真のAI判定を使うには

任意機能です。設定しなくても手動入力でアプリは使えます

  1. Anthropic APIキーを取得するconsole.anthropic.com でアカウントを作成し、「API Keys」からキー(sk-ant-...)を発行します。従量課金制で、写真1枚あたりのコストはごくわずかです。
  2. アプリの設定タブに登録するアプリを起動し、「⚙️ 設定」タブの「Anthropicキー」欄に取得したキーを貼り付けて保存します。キーはこの端末のブラウザ内にのみ保存されます。
  3. 写真から追加を使う「🍽️ 食事」タブ→「📷 写真から追加」で撮影・または写真ライブラリから選択すると、AIが料理名とカロリーを自動入力します。内容は保存前に自由に修正できます。

ホーム画面への追加方法

ネイティブアプリのように使えます

📱 Android(Chrome)

  1. Chromeでこのアプリのページを開く
  2. 右上の「⋮」メニューをタップ
  3. 「アプリをインストール」または「ホーム画面に追加」をタップ
  4. 表示名を確認して「インストール」

🍎 iPhone(Safari)

  1. Safariでこのアプリのページを開く(他のブラウザ不可)
  2. 下部の共有アイコン(四角に上矢印)をタップ
  3. 「ホーム画面に追加」を選択
  4. 表示名を確認して右上の「追加」をタップ

今日の記録から、はじめてみませんか

登録不要・完全無料。データはあなたの端末だけに残ります。

📱 アプリを起動する

記録データ(食事・体重・血圧)はすべてお使いの端末のブラウザ内にのみ保存され、外部に送信・共有されることはありません。

写真からのカロリー判定機能を使う場合のみ、写真がAnthropicのAPIへ送信されます(ご自身のAPIキーが必要です)。
